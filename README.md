# Pixel Auto Dialer & Flash 📱⚡

یک اپلیکیشن اندروید نیتیو (Kotlin) اختصاصی برای **Google Pixel 9a (اندروید ۱۵)** جهت برقراری تماس‌های پیوسته و هوشمند، تشخیص پاسخ طرف مقابل و روشن کردن خودکار فلش (چراغ‌قوه).

---

## قابلیت‌های کلیدی

1. **شماره‌گیری خودکار و متناوب (Redial Loop):** شماره‌گیری مکرر شماره‌های اداری، سفارت، نوبت‌دهی یا شماره‌هایی که پاسخگو نیستند.
2. **قطع خودکار بعد از ۲۰ ثانیه (Hang-up Watchdog):** در صورتی که بعد از ۲۰ ثانیه (یا زمان دلخواه شما) تماس پاسخ داده نشود، تماس قطع شده و بعد از ۳ ثانیه مجدداً برقرار می‌شود.
3. **تشخیص دقیق برقراری تماس (Call Answer Detection):** با بهره‌گیری از Accessibility Service و پایش تایمر تماس گوگل فون (`00:01`)، به محض برقراری مکالمه آن را تشخیص می‌دهد.
4. **روشن شدن چشمک‌زن/ممتد فلش گوشی (Strobe Flashlight):** به محض اینکه طرف مقابل گوشی را برداشت، فلش گوشی روشن می‌شود تا بدون نیاز به نگه داشتن گوشی روی گوش، متوجه پاسخگویی شوید.
5. **سرویس پس‌زمینه پایدار (Foreground Service):** برنامه همراه با اعلان پایدار در نوار وضعیت فعال می‌ماند و حتی در صورت بستن صفحه متوقف نمی‌شود.

## نحوه دریافت فایل APK آماده از گیت‌هاب (۲ دقیقه بدون نیاز به کامپیوتر)

پروژه به همراه فایل کانفیگ **GitHub Actions** تنظیم شده است. برای دریافت فایل APK:

1. یک مخزن (Repository) جدید در اکانت **GitHub** خود ایجاد کنید.
2. کدهای این پوشه را داخل آن پوش (Push) کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for PixelAutoDialer"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
3. در گیت‌هاب وارد برگه **Actions** شوید؛ می‌بینید که عملیات **Build Android APK** به صورت خودکار آغاز شده است.
4. پس از ۱ تا ۲ دقیقه و سبز شدن تیک بیلد، وارد جزئیات آن شوید و در بخش **Artifacts**، فایل زیپ **`PixelAutoDialer-Debug-APK`** را دانلود کنید.
5. فایل `app-debug.apk` را روی گوشی پیکسل 9a خود نصب نمایید.

---

## نحوه بیلد در Android Studio (روی کامپیوتر)

1. پوشه پروژه را با **Android Studio** باز کنید.
2. اجازه دهید Gradle فرآیند Sync را انجام دهد.
3. از منوی بالا به مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** بروید.
4. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته خواهد شد.

---

## راه‌اندازی و مجوزها روی گوگل پیکسل 9a

پس از نصب برنامه روی گوشی:
1. برنامه را باز کرده و مجوزهای **تماس (Phone)**، **دوربین (Camera)** و **اعلان (Notifications)** را تایید کنید.
2. بر روی دکمه نارنجی **«فعال‌سازی دسترسی خودکار (Accessibility)»** بزنید:
   * در تنظیمات گوشی به مسیر **Accessibility > Downloaded apps** بروید.
   * برنامه **Pixel Auto Dialer & Flash** را انتخاب کرده و سوییچ آن را فعال (ON) کنید.
3. در تنظیمات برنامه (یا تنظیمات باتری گوشی):
   * وارد **App info > Battery** شوید و حالت باتری را روی **Unrestricted** بگذارید تا سیستم‌عامل در پس‌زمینه برنامه را متوقف نکند.
4. شماره مقصد را وارد کرده و دکمه **شروع تماس متناوب** را فشار دهید!
